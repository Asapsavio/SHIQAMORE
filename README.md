# Nje_here-distributors

Practice system for a Nairobi cosmetics wholesale/retail distributor.

I am learning software engineering by building tools this kind of business actually uses:
- a simple company website
- cash, M-Pesa, and collect-in-shop sales
- stock that walk-in and online orders share
- an owner dashboard
- purchase/discount approvals with email and an audit trail
